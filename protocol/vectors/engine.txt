# Executable specification of the hand-off coordinator, shared by the C# and Kotlin test suites.
#
#   scenario <name>              starts a scenario with a fresh engine
#   settings k=v ...             role=phone|pc headsets=A,B prefer=phone|pc|none return=stay|return calls=on|off apps=id:auto|ask|ignore,...
#   > <event>                    feed an event; the "<" lines after it are the exact actions expected, in order
#   < <action>                   (an event with no "<" lines must produce no actions)
#   > wait <ms>                  advance the clock (not an event)
#   end
#
# events:  peer up|down · headset <h> here|away · play <app> · stop <app> · answer <id> yes|no · timer <name> · call on|off
#          recv claim <h> <id> · recv released <h> <id|-> <why> · recv deny <h> <id> <why> · recv config <hs> prefer=<p> return=<r>
#          recv state <h> here|away
# actions: pause|resume <app> · release|take <h> · send <msg> · ask <id> <app> · timer <name> <ms> · cancel <name> · notify <text>
#
# Each side tells the other whether a headset is connected to it (`state`): the phone when the link comes up, the PC
# once it has the phone's config, and both whenever the headset's link to them changes. Some headsets can hold two
# connections at once; then "here" alone doesn't mean the sound comes from here. A play only moves the headset when
# the peer says it has it.

scenario phone takes the headset from the PC
settings role=phone headsets=HS
> peer up
< send config HS prefer=phone return=stay
< send state HS away
> recv state HS here
> play spotify
< pause spotify
< send claim HS 1
< timer claim 2500
> stop spotify
> recv state HS away
> recv released HS 1 claim
< cancel claim
< take HS
< timer take 8000
> headset HS here
< send state HS here
< cancel take
< resume spotify
> play spotify
end

scenario PC gives the headset up when the phone claims it
settings role=pc headsets=HS
> headset HS here
> play brave.exe
> peer up
> recv claim HS 1
< pause brave.exe
< release HS
< timer release 4000
> stop brave.exe
> headset HS away
< send state HS away
< cancel release
< send released HS 1 claim
end
